# SBTi target-setting report

Read `definition.json` and the frozen target-method references before analysis.

## Domain decisions

- Establish organization, sector, base year, inventory boundary, Scope totals, target method, target year, and scope coverage.
- Check that base-year values and target statements use compatible organizational boundaries and Scope 2 approaches.
- Express reductions as proposals unless an authoritative source proves commitment, submission, or validation status.
- Separate near-term and net-zero targets and preserve distinct Scope 1+2 and Scope 3 coverage.
- Present renewable-electricity and beyond-value-chain commitments separately from inventory reductions.
- Do not invent annual pathways from start and end values unless a registered pathway method is selected.

Ask for blocking baseline or target information. Never state that SBTi validated a target without verifiable status evidence and date.
