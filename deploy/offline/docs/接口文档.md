# 接口文档

部署包根目录的 `openapi.json` 是从导出时实际 Dev API 镜像生成的完整接口规范，包含所有路径、请求参数、响应模型和状态码。部署后还可访问：

- Swagger UI：`http://<API_HOST>:<API_PORT>/docs`
- ReDoc：`http://<API_HOST>:<API_PORT>/redoc`
- OpenAPI JSON：`http://<API_HOST>:<API_PORT>/openapi.json`

## 鉴权

管理类接口先调用 `POST /api/v1/auth/login`，然后在请求头使用：

```text
Authorization: Bearer <access_token>
```

外部文档提交使用独立凭证头；实际名称以包内 `openapi.json` 为准。内部报告 Agent 接口使用服务间 Token，不应暴露到公网。

## 接口分组

- 身份认证：登录、当前账号。
- 数据集：创建、列表、详情、修改、删除、目录管理。
- 文档：上传、列表、详情、预览、分块、重试、重解析、删除。
- 外部文档审核：提交、待审核列表、原文件下载、通过/拒绝。
- 模型配置：模型配置的创建、查询、修改、删除。
- 检索与对话：三路召回、RAG 流式生成、Pi Agent 流式对话和就绪检查。
- 文档分析：分析任务、状态、结果和 DOCX 导出。
- 报告：模板、任务、补充问题、重试、取消和报告产物。
- 系统：存活检查与依赖状态。
- 内部接口：报告 Agent 上下文、检索、计算、检查点与提交。

## 流式接口

对话接口使用 Server-Sent Events。客户端必须支持长连接，并把代理层的读取超时设置为大于应用生成超时。HTTP 200 只表示流已建立；必须继续处理事件中的完成或错误状态。

## 错误处理

常见状态码：

- `400`：业务请求不合法。
- `401`：未登录、Token 无效或外部提交凭证错误。
- `403`：账号角色无权操作。
- `404`：数据集、文档或任务不存在。
- `409`：名称冲突、状态冲突或任务已经处理。
- `422`：字段校验失败。
- `500/502/503`：应用、上游模型或基础设施异常。

联调时应直接导入 `openapi.json` 到 Postman、Apifox 或其他 OpenAPI 客户端，避免手工维护接口副本产生漂移。
