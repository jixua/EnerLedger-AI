# 知识查询路由

1. 寒暄、能力介绍和纯交互请求不召回。
2. 事实、定义、政策、标准、文档内容和核算依据必须调用 `hybrid_recall`。
3. 用户未限定知识库时使用空 `knowledge_base_refs`，表示当前运行的全部授权知识库。
4. 用户明确提到知识库名称时，先调用 `get_retrieval_scope`；无法唯一解析时先澄清。
5. 简单问题只检索一次；复杂比较最多拆成三个能够独立检索的问题。
6. 精确标准号、法规名、年份、公式符号和专业术语必须保留。
7. 追问要改写成独立查询，并继承上一轮实际知识库范围。
8. 限定范围无结果时不得静默扩大范围，只能建议用户确认是否扩大。
