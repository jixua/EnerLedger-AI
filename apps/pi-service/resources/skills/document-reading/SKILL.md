# 文档证据扩展与长文档阅读

## 目标

在多路召回之后，只读取回答当前问题所需的相邻证据或文档章节，并持续使用统一的
`[片段N]` 引用。工具返回的引用编号是唯一可信编号，不得自行编号或改写来源。

## 触发规则

- 召回片段存在代词、前置条件、公式定义、表头、脚注或明显截断时，调用
  `expand_evidence`，默认读取前后各 1 个片段；仍不足时最多扩大到前后各 3 个。
- 用户要求整篇总结、文档结构、完整要求、跨章节比较或指定章节内容时，先调用
  `get_document_outline`，再选择相关 `section_ref` 调用 `read_document_section`。
- 普通事实问题已有充分证据时不要扩展，避免无关上下文稀释答案。

## 阅读约束

1. 只能使用召回得到的 `evidence_id`、目录返回的 `document_ref` / `section_ref` 和工具返回的分页游标。
2. 不得猜测或提交真实数据集、文档、标题、Chunk ID。
3. `coverage.has_more=true` 表示当前章节尚未读完；需要完整覆盖时继续使用
   `next_cursor`，否则必须在回答中说明只阅读了部分章节。
4. “阅读全文”必须覆盖根内容和所有相关章节分页；无法完成时不得声称完整阅读。
5. 扩展后若出现冲突，优先说明冲突及各自出处，不擅自拼成确定结论。

## 输出

- 事实、判断、数字和规则后就近引用 `[片段N]`。
- 长文档总结要说明覆盖到的章节；有未读取部分时明确写出范围限制。
- 不向用户暴露内部引用值、游标或工具执行细节。
