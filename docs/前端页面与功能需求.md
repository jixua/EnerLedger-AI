# 能碳会计 AI 智能体前端页面与功能需求

## 1. 产品范围

前端不区分用户端与管理端，在同一应用中覆盖：

- 基于数据集的对话与 SSE 流式生成。
- 数据集创建、编辑、删除与模型绑定。
- 文档上传、异步解析、重试、重新解析与删除。
- 对已完成文档调用大模型分析，生成带来源映射的 Markdown 报告。
- BM25、Sparse、Dense 三路召回和融合结果检查。
- 模型配置创建、编辑、API Key 轮换、启停与删除。
- 文档处理队列与基础设施状态查看。
- 第三方采集资料的原文件查看、人工通过与拒绝。

本期不建设会话持久化、多租户权限管理、音视频对话或可视化流程编排。系统提供单管理员登录，不开放注册。

## 2. 产品原则

1. **对话优先**：首页就是对话，输入框必须在首屏可见，不在其上放置大型配置卡或统计 Hero。
2. **专业术语**：统一使用“对话”“文档”“数据集”“混合检索”“召回片段”“来源与引用”。
3. **状态真实**：不将未验证的服务显示为正常，不将本地对话伪装成服务器会话历史。
4. **异步处理**：上传成功表示文档已入队，不表示解析与索引已完成。
5. **引用可追溯**：模型回答中的 `[片段N]` 必须与实际纳入上下文的片段编号一致。
6. **响应式完整**：924px 等中等视口不允许裁切标题、文件名、错误信息或操作。

## 3. 信息架构

| 一级导航 | 路由 | 主要功能 |
| --- | --- | --- |
| 对话 | `/` | 多数据集混合检索、SSE 回答、来源抽屉 |
| 知识库 | `/datasets` | 数据集列表、创建和入口 |
| 数据集详情 | `/datasets/:id` | 文档、检索测试、设置 |
| 文档预览 | `/datasets/:id/documents/:documentId` | 解析正文、分片边界和解析信息 |
| 分析报告 | `/datasets/:id/documents/:documentId/analysis` | 报告生成、Markdown 预览、下载与引用核对 |
| 文档处理 | `/tasks` | 基于 document 记录聚合的解析队列 |
| 资料审核 | `/crawler/review` | 第三方上传资料审核与目标数据集选择 |
| 资料采集 | `/crawler` | arXiv 主动采集（仅管理员） |
| 模型配置 | `/models` | 模型全生命周期与密钥轮换 |
| 服务状态 | `/system` | API 存活与依赖状态证据 |
| 账号登录 | `/login` | 使用预配置管理员或资料审核员账号登录；无注册入口 |

`/playground` 仅作为旧地址兼容，重定向到 `/`。

## 4. 全局应用框架

- 左侧导航使用浅色面板和蓝绿色选中态，不使用黑色、红色或珊瑚色选中背景。
- 顶部栏显示当前模块、API 连接状态和“新建对话”。
- 视口宽度小于等于 1080px 时，侧栏切换为抽屉，优先保证内容完整。
- 基础配色：画布 `#f4f6f3`，面板 `#fbfcfa`，正文 `#243632`，主色 `#3f766c`。

## 5. 对话页

### 5.1 空态

- 居中展示标题、一句能力说明和输入框。
- 数据集与对话模型选择放在输入框工具栏，不独立占用大卡片。
- 建议问题只作为轻量快捷入口。
- 当没有会话持久化 API 时，明确显示“仅保存在当前页面”。

### 5.2 消息态

- 用户与助手消息使用同一单列，不常驻空白来源栏。
- 第一条消息后，输入框停靠在对话区底部。
- `stream_started` 显示混合检索状态。
- `recall_done` 缓存召回片段和降级检索路，不中断后续生成。
- `answer_delta` 追加渲染 Markdown。
- `answer_done` 作为正常终态，包括无召回上下文时的固定回答。
- 生成中可停止，完成后可复制回答或按需打开来源抽屉。

### 5.3 来源抽屉

每个召回片段至少展示：

- `citation_index` 及对应的 `[片段N]`。
- `filename`、`doc_id`、`dataset_id`。
- `page` 或 `page_range`。
- `document_version`。
- `chunk_index` 和 `chunk_id`。
- `fused_score` 与 BM25 / Sparse / Dense 分数。
- 实际纳入上下文的片段正文。

## 6. 数据集

### 6.1 列表与创建

- 按名称和描述搜索。
- 卡片展示文档数、可用文档数和更新时间。
- 创建时必选稠密与稀疏向量模型，对话模型可选。
- 编辑入口进入详情设置页。
- 只允许删除空数据集；非空数据集显示明确的禁用原因。

### 6.2 详情

页头与摘要必须在中等视口完整展示。页签包括：

1. **文档**：上传、虚拟文件夹分类、状态、解析结果和生命周期操作。
2. **检索测试**：仅执行混合检索，展示来源与分数。
3. **设置**：更新名称、描述和模型绑定，删除空数据集。

文档列表在宽屏使用响应式网格，当可用宽度不足时切换为卡片；禁止依赖固定 880px 表格。文件名与错误文本允许换行。

文件夹是数据集内的单层虚拟分类，仅用于用户区分文件类型。支持新建、重命名、删除、按文件夹筛选和移动文档；未指定文件夹的文档统一展示为“未分类”。删除文件夹不删除文档，文档回到“未分类”；分类变更不改变对象存储路径、解析版本或检索索引。

## 7. 文档上传与解析队列

### 7.1 上传

- 支持 PDF、DOCX、HTML、HTM，默认单文件上限 100 MiB。
- 前端可批量选择，按文件发送上传请求。
- 成功响应为 `202 Accepted`，文档状态为 `QUEUED`。
- 上传弹窗不等待解析、分块和索引完成。

### 7.2 文档状态

| 状态 | 前端文案 | 允许操作 |
| --- | --- | --- |
| `QUEUED` 且未尝试 | 排队中 | 查看、删除 |
| `QUEUED` 且 `attempt_count > 0` | 待重试 | 查看、删除 |
| `PROCESSING` | 处理中 | 查看；禁用删除 |
| `READY` | 已完成 | 检索、对话、重新解析、删除 |
| `FAILED` | 失败 | 重试、删除 |

队列基于 MySQL document 记录的状态、lease 和延迟重试字段，不单独建立任务表。`/tasks` 是文档状态的跨数据集聚合视图。

第三方爬虫上传的资料先进入 `/crawler/review` 审核区。审核卡片展示原目标数据集、来源页面、标题、
文件名、大小、采集器和提交时间，并允许已授权审核身份查看 MinIO 原文件。点击“通过并解析”前，
必须选择最终入库数据集。只有审核通过后才进入普通文档列表和 `/tasks`；拒绝资料保留审核备注，但不进入解析与召回。受限资料审核员只可访问“对话”与“资料审核”，其他管理页面和对应后端接口仍仅限管理员。

### 7.3 企业文档分析

- 文档预览页不内嵌分析内容；仅 `READY` 文档显示“分析报告”入口，跳转到独立报告页面。
- 分析报告页调用真实分析 API；生成中可取消，失败后可重试，并提供“返回文档与分片预览”入口。
- 报告按 Markdown 渲染，结构参考产品碳足迹评价报告，覆盖报告摘要、评价对象与方法、边界、功能单位、生命周期清单、碳足迹评价、数据质量、不确定性、规范性检查、资料缺口与分析限制。
- 事实性发现使用 `[文档片段N]`，面板展示模型实际引用的分片、页码和摘要映射。
- 支持复制 Markdown、下载 `.md` 和下载 DOCX；DOCX 由当前已持久化报告导出，不重复调用大模型。报告按当前文档版本保存到 MinIO，页面进入时自动加载最近一次成功报告。
- 文档版本发生变化时清除旧结果，避免把上一版本报告显示为当前结论。

## 8. 模型配置

- 按能力和关键词筛选。
- 创建时配置厂商、模型 ID、能力、协议、官方 API 地址与 API Key。
- 编辑时可修正显示名、模型 ID、API 地址、API Key 和启用状态。
- 修改密钥或端点会提升 `snapshot_version`；列表永不回显明文 API Key。
- 厂商、协议与能力在已有配置中为不可变语义。
- 被数据集绑定的配置删除时显示后端 `409` 原因，不先从列表移除。

## 9. 接口映射

| 功能 | 接口 |
| --- | --- |
| 数据集列表 / 创建 | `GET/POST /api/v1/datasets` |
| 数据集详情 / 更新 / 删除 | `GET/PATCH/DELETE /api/v1/datasets/{id}` |
| 文件夹列表 / 创建 | `GET/POST /api/v1/datasets/{id}/folders` |
| 文件夹重命名 / 删除 | `PATCH/DELETE /api/v1/datasets/{id}/folders/{folderId}` |
| 文档列表 / 上传 | `GET/POST /api/v1/datasets/{id}/documents` |
| 文档详情 / 分类 / 删除 | `GET/PATCH/DELETE /api/v1/documents/{id}` |
| 文档重试 | `POST /api/v1/documents/{id}/retry` |
| 文档重新解析 | `POST /api/v1/documents/{id}/reparse` |
| 企业文档分析读取 / 生成并持久化 | `GET/POST /api/v1/documents/{id}/analysis` |
| 模型列表 / 创建 | `GET/POST /api/v1/llm/configs` |
| 模型更新 / 删除 | `PATCH/DELETE /api/v1/llm/configs/{id}` |
| 混合检索 | `POST /api/v1/recall` |
| 对话流 | `POST /api/v1/rag/stream` |

除存活检查和登录外，所有业务请求带 Bearer JWT。前端只有在后端成功响应后才更新删除结果；令牌失效后返回登录页。

## 10. 验收标准

- `/` 首屏必须可直接输入，不显示工作台 Hero、大型范围配置卡或常驻空来源栏。
- 对话可选数据集与模型、流式渲染、停止、复制和查看引用。
- 无召回上下文依然收到终态回答，不停留在 `recall_done`。
- 数据集、模型与文档生命周期操作均有真实 API 交互和错误反馈。
- 文档上传后显示排队状态，失败可重试，完成可重新解析。
- 已完成文档可生成固定结构的 Markdown 分析报告，并复制、下载和核对引用分片。
- 来源展示文件名、页码/页码范围、版本、分块与引用编号。
- 924px、620px 和常见宽屏下无水平裁切，文件名与错误可换行。
- 导航、按钮、选中态和大面积背景均不使用黑色、红色或珊瑚色作为主强调。
- `npm run build` 与 `npm run test:sites` 通过。
